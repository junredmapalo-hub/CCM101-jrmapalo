# Mission Reflection

The cloud platform that impressed me the most was AWS because of its broad range of cloud services and its ability to support different types of organizations and workloads. During this mission, I also learned that AWS, Microsoft Azure, and Google Cloud Platform share many similarities because all three provide cloud computing resources such as virtual machines, storage, networking, databases, identity management, and Kubernetes services. They also offer scalable infrastructure and global cloud resources, which allow organizations to deploy applications and manage their workloads more efficiently. However, the best cloud platform is not always the same for every organization because business requirements strongly influence the decision. Factors such as budget, existing technology, workload requirements, scalability, performance, and business goals must be considered. For example, an organization that already uses Windows Server, Microsoft 365, and Active Directory may benefit more from Azure because of its strong Microsoft integration, while an AI research company may prefer Google Cloud because of its AI and machine learning capabilities. Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider requires more than simply selecting the most popular platform. I learned to study the client's situation, compare available services, identify the provider's strengths, and then recommend a solution that best fits the client's actual needs. This mission also improved my GitHub Cloud Computing Portfolio by adding organized Markdown documentation, research about AWS, Azure, and GCP, comparison tables, client recommendations, Linux investigation results, and screenshots as evidence. Overall, the activity helped me understand how cloud technologies can be evaluated from both technical and business perspectives while also improving my ability to document and present cloud solutions professionally.
