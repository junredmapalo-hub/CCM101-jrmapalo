## Core Infrastructure Services

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
| :--- | :--- | :--- | :--- |
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 / Amazon EBS | Azure Blob / Disk Storage | Cloud Storage / Persistent Disk |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
Amazon Web Services (AWS) offers the broadest range of services due to being the pioneer in the public cloud market with early entry advantage. It provides the most comprehensive depth of features across compute, serverless architectures, managed databases, and global infrastructure edge locations.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Microsoft Azure is recommended for organizations relying heavily on Microsoft products because of its native software ecosystem integration. It seamlessly integrates with Active Directory, Windows Server, Office 365, and SQL Server while allowing companies to optimize licensing costs using Azure Hybrid Benefit.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform (GCP) is widely recognized in these domains as the original creator of Kubernetes through its industry-standard Google Kubernetes Engine (GKE). Additionally, GCP leads in AI/ML capabilities through Vertex AI, custom Tensor Processing Unit (TPU) hardware, and advanced data analytics solutions.

### 4. What similarities did you observe among the three cloud providers?
All three cloud providers structure their infrastructure around the same fundamental building blocks: virtual compute nodes, block/object storage solutions, virtual network isolation, and centralized access control. Furthermore, each provider utilizes pay-as-you-go pricing models, global availability zones, and strict enterprise security controls.
