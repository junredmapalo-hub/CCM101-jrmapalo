# Laboratory 02: Build the Cloud Infrastructure Blueprint

## Mission Overview
In this laboratory activity, an investigation of cloud infrastructure components was conducted using a cloud-hosted Linux server environment provided by KillerCoda. Core hardware and software system specifications were inspected, basic infrastructure components were mapped to public cloud service abstractions (AWS, Azure, GCP), and technical documentation was authored within a structured GitHub portfolio repository[cite: 1].

## Objectives
* Identify and explain the major physical and virtual components of cloud infrastructure[cite: 1].
* Investigate Linux system properties, hardware metrics, and network interfaces using command-line diagnostic tools[cite: 1].
* Differentiate core cloud service categories: compute, storage, networking, and identity management[cite: 1].
* Compare equivalent infrastructure offerings from major cloud vendors (AWS, Azure, GCP)[cite: 1].
* Construct clear technical documentation using standard Markdown formatting[cite: 1].

## Cloud Infrastructure Components
* **Compute:** Processing nodes and runtime memory units (CPUs and RAM) responsible for executing application logic and system tasks[cite: 1].
* **Storage:** Non-volatile block, object, and file storage systems used to persist operating system images, application code, and user data[cite: 1].
* **Networking:** Digital communication channels, IP interfaces, subnets, and routing rules that connect client endpoints with backend server workloads[cite: 1].
* **Identity and Access Management (IAM):** Authentication and authorization framework that controls access permissions across cloud resources.

## Tools Used
* **KillerCoda Playground:** Cloud-hosted Linux terminal environment[cite: 1].
* **Linux CLI Utilities:** System inspection tools (`cat`, `uname`, `lscpu`, `free`, `df`, `ip`)[cite: 1].
* **GitHub:** Portfolio repository hosting and version control[cite: 1].
* **Diagramming Tool (Excalidraw / Draw.io / Figma):** Visual cloud architecture diagram creator[cite: 1].

## Linux Commands Executed
* `hostname`: Retreived the system network hostname[cite: 1].
* `cat /etc/os-release`: Displayed detailed Linux operating system distribution information[cite: 1].
* `uname -r`: Printed the active Linux kernel release version[cite: 1].
* `lscpu`: Queried detailed CPU architecture, core count, and processor model specifications[cite: 1].
* `free -h`: Examined total, used, and available system RAM memory[cite: 1].
* `df -h`: Inspected disk volume capacities, storage utilization, and filesystem mount points[cite: 1].
* `ip a`: Listed network interface configurations, MAC addresses, and assigned IP addresses[cite: 1].
