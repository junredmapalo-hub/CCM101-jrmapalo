# Laboratory Activity 1: Mission 1 - Welcome to the Cloud

## Mission Overview
This mission serves as the onboarding challenge for a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies. It covers fundamental Linux navigation, user administration, system assessment, Markdown documentation, and GitHub repository management.

## Objectives
- Access and interact with an Ubuntu Linux environment via KillerCoda.
- Perform user account creation and sudo access configuration.
- Inspect system hardware specs, kernel versions, and storage allocations.
- Construct structured Linux workspaces and manage files.
- Establish a version-controlled Cloud Computing portfolio on GitHub.

## Activities Performed
1. Created user `jrmapalo` with Bash shell and administrative privileges.
2. Audited Linux environment hardware resources and system kernel.
3. Created directory workspace structure (`Documents`, `Notes`, `Reports`, `Screenshots`).
4. Authored technical documentation using Markdown formatting.
5. Synced local workspace files and evidence screenshots to GitHub.

## Linux Commands Used
- `useradd`, `passwd`, `usermod`: User management and privilege elevation.
- `su`: Switching user identity.
- `whoami`, `pwd`, `hostname`: Context and path verification.
- `cat /etc/os-release`, `uname -r`, `lscpu`: Gathering system information.
- `free -h`, `df -h`: Memory and disk space diagnostics.
- `mkdir -p`, `ls -l`: Directory creation and structure auditing.

## Skills Learned
- Linux user and group permission administration.
- System information retrieval and resource auditing.
- Professional technical documentation using Markdown.
- Portfolio repository setup with Git version management.
